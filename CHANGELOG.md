# Changelog

## 0.1.0

The first release of Inkstand: a focused, open-source writing app for Markdown, in the spirit of iA Writer.

- **Writing:** Markdown shown in the text colour with heading marks hanging in the margin; iA Writer Mono, Duo and Quattro fonts; focus mode, typewriter mode, syntax highlight and style check; smart typography; table editing; callouts; read aloud.
- **Authorship:** named authors (people, AI tools, references), Mark As and Paste Edits From, stored inside the document so it travels with the file.
- **Library:** your own folders in two columns, with sort and filter bars, an iA Writer-compatible search language, rule-based smart folders, favourites, hashtags, version history and wiki links.
- **Preview and export:** live preview with templates (including iA Writer `.iatemplate` bundles), Fit Page view, and export to PDF, Word, HTML, Markdown and plain text; Page Setup; publishing to WordPress, Ghost, Medium and Micro.blog.
- **System:** `inkstand://` URL commands compatible with iA Writer's, light and dark themes, and signed and notarized macOS builds.
